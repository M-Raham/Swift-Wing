# ✈️ Swift Wing

**Swift Wing** is a front-end web project simulating a travel and tour company, designed to provide users with an engaging interface to explore various travel destinations and packages. Built using **HTML**, **CSS**, and **JavaScript**, this project offers a glimpse into a travel agency's offerings.

> **Note**: This project focuses solely on the front-end and is not responsive.

## 🌐 Live Demo

Experience the Swift Wing website: [https://m-raham.github.io/Swift-Wing/](https://m-raham.github.io/Swift-Wing/)

## 📂 Project Structure

The repository includes the following key files and directories:

- `index.html`: The main landing page.
- `aboutus.html`: Information about the company.
- `services.html`: Details of services offered.
- `pkg.html`: Available travel packages.
- `descover.html`: Discover various destinations.
- `login.html` & `signup.html`: User authentication pages.
- `style.css`: Global styles.
- `aboutus.css`, `services.css`, `pkg.css`, `discover.css`, `book.css`, `LRstyle.css`: Page-specific styles.
- `video.mp4`: Media asset used on the site.
- `Images/`: Directory containing image assets.
- `Icons/`: Directory containing icon assets.

## 🚀 Getting Started

To view or modify the project locally:

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/M-Raham/Swift-Wing.git
   cd Swift-Wing
   ```

2. **Open in Browser**:

   Open `index.html` in your preferred web browser to view the site.
